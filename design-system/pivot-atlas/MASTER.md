# Pivot Atlas · Design System

## 产品与任务
面向跨市场研究者的本地行情研究工作台。核心顺序：判断数据是否可用 → 选择市场和周期 → 比较关键点位 → 打开 K 线核对来源。保留 48 标的、日历判定、缓存标记与全部计算规则。不是营销首页，不新增买卖建议。

## 设计决策
UI UX Pro Max 检索命中 Financial Dashboard。采用其 Minimalism & Swiss Style 辅助方向、等宽数字与可访问性规范；不采用自动推荐的 Enterprise Gateway 销售首页、霓虹和列表弹跳动画，因为不符合研究操作场景。
定位为“精密研究台”：深墨色导航、纸白数据区、单一深青品牌色。保留原有浅色研究阅读习惯。通过非对称导航与大字号中文标题建立辨识度，不以装饰抢占行情空间。

## Tokens
背景 #f4f6f7；表面 #ffffff；正文 #172e36；次要文字 #52666e；边框 #d7e0e3；品牌 #135b63；导航 #142d35。
阻力 #235f96；轴心 #a14432；支撑 #236a51。颜色始终与 R/P/S 标签配合。非文本边界与焦点必须清晰，普通文字对比至少 4.5:1。
字体：系统中文 PingFang SC / Microsoft YaHei，西文系统 sans；数字 SFMono-Regular / Consolas。避免外部字体依赖与加载跳动。
正文 14–16px，表格数字 13px，辅助信息最低 12px，标题 36px（手机 28px）。数字 tabular-nums。
间距：4 / 8 / 12 / 16 / 24 / 32 / 48。低密度用于页面节奏，数据表保留可比性。圆角：控件 6px，容器 10px；导航与分组平面化。

## 页面与组件
1. 固定窄导航：品牌、概览、关注、市场、口径说明。手机使用页内市场标签和关注入口。
2. 标题和刷新/导出工具。状态概览为平面信息带，不做四张悬浮卡片。
3. 点位用途作为明确工作模式，附当前/下期含义。
4. 市场表：分组标题、资产固定列、右对齐数字、轴心浅色背景。源周期移至详情，表格保留适用日期，减少重复。
5. 资产详情：有名称的原生 dialog、显式关闭、周月选择、K 线、源数据。历史分段与下期预览规则保持。
6. 空态/加载/旧数据/失败均使用明确文字；不把缓存当实时连接。

## 交互与可访问性
可点击控件至少 44px 高，键盘 focus-visible 3px。选择状态提供 aria-pressed。滚动数据区有名称、可键盘聚焦。搜索有可访问名称。弹窗关闭回到触发入口。
仅使用 160ms 的颜色/边框反馈，不做入场、数字滚动、无限动画。prefers-reduced-motion 禁用过渡。
手机不出现整页横向溢出；宽表、K 线在有提示的局部区域横向滚动。375 / 768 / 1024 / 1440px 验证。

## 优先级
用户需求和可访问性 > 本规范 > 视觉创意。采用现有原生 HTML/CSS/JS，不为视觉改版引入框架。

## Polish 补充
资产身份列显示数据状态；周/月可用数量分别标注。桌面压缩重复说明，保留顶部口径入口。K 线仅一个 Tab 入口，左右箭头/Home/End 切换日期；弹窗重绘保持当前控件焦点。辅助日期与来源 12px。用途区采用平面底色，不使用厚侧边装饰线。

## 视觉识别更新
增加本地 icons.mjs 几何线性图标，24px 画布、1.65px 笔画；装饰图标 aria-hidden，操作名称保留文字。市场分组共享明确的类别图标。标题区采用本地 market-globe.svg 经纬球面插图，表达跨市场覆盖，不是地理坐标或行情数据。手机缩小并降低插图对比，保持文字可读。不添加无限动画。

## 研究效率更新
桌面市场选择只保留侧栏，手机保留横向标签。顶部统计压缩，方法详情仍可通过帮助查看。失败和旧数据计数可点击筛选，再点取消；选中状态提供 aria-pressed，清除筛选恢复全部。状态筛选会清除市场、关注和搜索，之后可进一步叠加筛选。插图使用独立网格区域，不覆盖操作按钮。
