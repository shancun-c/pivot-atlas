# 研究序列与日期传递

验收：研究表现使用独立序列；基金仅使用提供商拆分和分红调整后的收盘价，缺失/错位/非正/已知拆分边界未校正则拒绝计算，不能回退原价。行情缓存schema升级，保留旧数据供实际报价查看但不冒充复权序列。指数/现货、基金、连续期货和收益率分开排名；跨类别对照逐行声明口径，期货为连续报价变化而非持仓回报。原OHLC与枢轴不修改。

矩阵传递选中周期的真实基准/终点，必须所有所选标的具有一致有效端点，否则说明冲突，不默默改日期。对照锁定传入端点，取消旧组合关联并提示来源；保存保持兼容原有组合。

Context7工具不可用。依据Yahoo官方复权解释：https://in.help.yahoo.com/kb/adjusted-close-sln28256.html；通过实际chart响应核验adjclose数组与timestamp对应。无新依赖。本轮不增加滚动相关性或宏观因子数据。

## 数据核验与限制
实际Yahoo的515880.SS `adjclose` 在2025-12-31、2026-02-03、2026-07-06仍等于未调整收盘，拒绝使用。腾讯同标的 `sh515880` 的 `qfqday` 实际返回500条，去年末0.513、2026-09-30为0.626，两个拆分断点已调整。新增显式同标的映射，不用代理资产。已知拆分日期来自发行人公告（二月除权2月3日、七月除权7月6日）：
- https://pdf.dfcfw.com/pdf/H2_AN202602031819506989_1.pdf
- https://vip.stock.finance.sina.com.cn/fund/go.php/vAkFundInfo_JJGKXX/q/5353201.phtml

基金研究字段必须独立提供，前复权/Adj Close按提供商口径标注，不声称精确税费后总回报。腾讯价格有报价精度限制，不能用手工拆分比推算替代真实序列。已知拆分日异常检查是保护措施，不是对所有公司行动已审计的保证。连续期货不伪造复权/滚动持仓收益，保留单独比较范围和明确标签。

本轮新增研究序列模块及回归测试：缺失/不合法复权数组、已知拆分未校正、研究来源失败不回退原价、矩阵基准冲突、真实日期传递、旧组合格式兼容。43项JS、44项Python测试通过。矩阵与对照均使用同一研究选择逻辑；缓存schema3促使旧行情刷新，旧基金缓存缺研究字段时明确不可用。
