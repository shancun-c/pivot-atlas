# 研究口径与流程改进

验收：矩阵增加统一截止日（要求该日有已结束观测）与各市场最新模式；本周/月/YTD无本期观测时不输出零回报；逐项展示历史起点、缺少基准原因。现有来源扩大至至少约1年请求，实际覆盖不足仍明确失败。

矩阵可选择2–4标的进入对照；对照可以锁定确切起止日期（必须为各序列共同日期，不能静默漂移），保存命名组合到当前浏览器并恢复。相关性暂保留共同区间算法，滚动相关性和宏观事件另轮实现。

无新前端依赖；Coinbase按官方单次最多300根限制分两段250日请求、排序去重，并剔除未结束日线。保留旧缓存，不强制删除；刷新时请求扩展历史。

## 使用
矩阵可切换日期口径、勾选2–4个标的进入对照，选择跨市场/价格与收益率范围时已选标的保留。对照支持固定起止日期，要求所有标的都有两个端点；区间内仍取共同日期，不填值。同名组合保存将更新，最多保存30组，仅在当前浏览器保留。滚动窗口或锁定日期及所选资产自动恢复。日期锁定统一端点，不等于统一市场收盘时刻。
