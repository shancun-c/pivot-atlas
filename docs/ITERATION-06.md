# Iteration 06 · 宏观传导

## 范围与设计
独立工作空间入口；复用现有深青导航、纸白研究区与原生控件（Operate模式）。按政策/曲线、实际利率/通胀定价、相对强弱分成三个研究视角；每个视角显示两条独立历史曲线、当前值、区间变化、日期、来源与解释限制。统一90/180/365自然日窗口，不自动贴宏观状态标签。

新增 macro_data.py（财政部XML与独立缓存）、public/macro.mjs（同日运算）、macro-view.mjs（视图）；修改server路由、app导航与样式。现有51资产和枢轴/九转算法保持。

## 数据与验收
- 官方财政部年度XML名义曲线 BC_2YEAR/BC_10YEAR、实际曲线 TC_10YEAR；独立来源缓存、失败保留并标失效、限制重试、拒绝时间倒退。
- 10Y−2Y=(10Y−2Y)×100 bp；10Y盈亏平衡代理=名义10Y−实际10Y（%），变化用bp。负实际利率合法。
- NDX/SPX、COMEX铜/金只取两条已结束日线的同日交集，比值标准化起点100。连续期货换月不等于可投资收益，铜/金原始单位不同。
- 不前填、不跨日相减；显示每条来源最新日与实际共同日期；不足2点、无效值或失效依赖只阻止相应指标。
- 只支持历史描述；窗口可能因历史覆盖不足而缩短，明确实际区间。不提供因果、预测或投资建议标签。
- 桌面和390px页面、切换窗口、来源失败状态、CSV和明细验证；有意义的运算/缓存回归测试；隔离部署保留回滚。
