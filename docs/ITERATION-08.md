# Iteration 08 · 日常宏观观察

## 范围与设计
沿用现有设计与数据源。macro.mjs增加近期变化、刷新依赖和最近观测选择；macro-view.mjs增加1/5/20观测间隔读数、日期游标/原生range和本视角刷新；app.js复用已有retryAsset，并拒绝全局刷新期间重复请求。样式、版本参数和有意义的回归测试同步更新。不新增依赖；纯本地逻辑与原生控件，无需Context7。

## 验收
- 短期变化使用当前日期口径的真实观测，必须有n+1个点；缺口不填补、标实际日期；收益率/利差用bp，比值用百分比。
- 图表鼠标移动/触摸点击定位最近真实日期，range支持键盘；共同模式同步本视角两图，独立模式不制造同步日期。
- 日期选择在后台重绘后保留；读数包含日期、单位，比值同时给原始值。
- 刷新本视角：独立模式只请求所需依赖，共同模式刷新全部六项依赖。禁用重复触发，报告可用/旧数据/失败；并发全局刷新时明确未执行。
- 桌面/390px验收；本站独立发布、保留上版回滚，不改已有服务器服务配置。
