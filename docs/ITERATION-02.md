# 跨资产对照
宏观研究任务：识别美元、利率、股票和商品是否呈现共同变化，作为后续研究线索，不自动推断因果或买卖信号。

- 2–4个独立标的；默认美元/黄金/美债收益率/标普；30/90/180自然日窗口。
- 保守剔除每个来源时区当天日线；以所有序列最早的最新日期锚定窗口，取共同日期，不前向填充。
- 价格以共同起点100标准化；收益率以共同起点累计bp变化，在独立纵轴面板展示。
- 横轴采用实际日历间距；提供全部共同日期的数据表。
- Pearson相关性按共同日期间的价格百分比变化或收益率bp变化计算（间隔可能跨多日），至少20个变动样本；常量序列不输出。不是价格水平相关性，不代表因果，同日期不保证同步收盘。
- 任何选中标的缓存失效/失败时，阻止整组输出；显示被剔除日期数和真实起止时间，避免悄悄缩小成另一组。
- 原有页面、数据源、枢轴和九转保持不变。原生JS/SVG，无新第三方依赖。

## 验证
35项JS测试、39项Python测试通过。浏览器实测“利率与风险资产”取64个共同日期、63个区间变动样本，价格与bp分轴；重复标的触发错误提示。390px文档无整页横向溢出。美元本地接口刷新失败时正确阻止该组输出，未冒用缓存。Impeccable机械检查仅命中原有style.css第18行侧边装饰警告，本次未修改该无关样式。
